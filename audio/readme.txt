# Egzamin certyfikatowy B1 — 6 testów

Interaktywna aplikacja do ćwiczenia polskiego egzaminu certyfikatowego B1.

## Uruchomienie lokalne
Otwórz `index.html` w przeglądarce. Folder `audio/` musi leżeć obok pliku.

## GitHub Pages
1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)** → Save
4. Adres: `https://<uzytkownik>.github.io/<repo>/`

Nagrania mp3 (~29 MB) są w folderze `audio/`.
